# ---------------------------------------------------------------------------
# INCIDENT 4: Authorization Bypass Attempt via Referer Injection
# ---------------------------------------------------------------------------
# A client was denied access to a player login endpoint because the referer
# pointed to an external gambling site — potential credential stuffing or
# cross-site request forgery.

[12/Oct/2021:12:02:07 +0100] [authz_core:error] [pid 19690] [client 203.0.113.201:14385] AH01630: client denied by server configuration: proxy:ajp://localhost:8009/platform/usergateway/userlogin, referer: https://www.example-casino.com/en/account/log-in

# ANALYSIS: The referer header shows an external gambling site's login page
# as the origin for a request to our player API. This is either a
# misconfigured integration partner or (more likely) a credential stuffing
# attack where stolen credentials from one platform are being tested against
# ours. The server correctly blocked the request based on origin validation.
