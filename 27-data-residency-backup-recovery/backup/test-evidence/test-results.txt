STEP 14: KEY ROTATION NOTES
-----------------------------
pgBackRest AES-256-CBC key rotation approach:
1. Archive old passphrase to /etc/pgbackrest/key-archive/
2. Update /etc/pgbackrest/pgbackrest.conf with new passphrase
3. Run stanza-create with new passphrase
4. Run full backup (new key applies to all new backups)
5. Old backups expire per retention policy (repo1-retention-full=7)
6. Old key required only for restoring from pre-rotation backups

Key rotation script: /scripts/chapter-27/backup/key-rotation.sh


POSTGRESQL 18 TDE NOTES
--------------------------
PostgreSQL 18 (released 2026) includes:
- Native Transparent Data Encryption (TDE) — cluster-level encryption
- Backup encryption improvements via pg_basebackup
- Not yet in pgBackRest 2.50 integration (as of April 2026)

RECOMMENDATION:
- Continue using pgBackRest AES-256-CBC for backup encryption
- pgBackRest encrypts both backup files AND WAL archives
- PG18 TDE encrypts at-rest on the primary — complementary, not a replacement
- TDE + pgBackRest encryption provides defense-in-depth
